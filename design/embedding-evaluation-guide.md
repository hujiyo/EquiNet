## 1. 概述：评估的目标

### 1.1 什么是Embedding模块？

在我们的项目中，Embedding模块由两部分组成：

```
输入数据（粗处理后）→ 细处理(FeatureNormalizer) → Embedding层 → 输出向量(d_model维)
```

- **细处理(FeatureNormalizer)**：QuantileTransformer + StandardScaler，将数据标准化
- **Embedding层**：一个 Linear(6, 48) 的线性层，将6维输入映射到48维空间

### 1.2 为什么要评估Embedding模块？

Embedding模块是整个模型的"第一关"，它的质量直接影响后续Transformer层的表现。评估的主要目标：

1. **表达能力**：输入能否被有效映射到有意义的表示空间？
2. **敏感性**：输入变化能否被正确反映到输出变化？
3. **多样性**：不同输入是否产生足够不同的输出？
4. **健康度**：是否存在死神经元或饱和问题？

## 2. Jacobian矩阵分析

### 2.1 原理

**Jacobian矩阵**描述了**多变量函数**的**一阶偏导数**。对于我们的Embedding模块：

```
f: ℝ^6 → ℝ^48
x = (Open, High, Low, Close, Volume, Exchange)  ∈ ℝ^6
y = f(x) ∈ ℝ^48
```

Jacobian矩阵 J 是一个 **6 × 48** 的矩阵：

```
J[i,j] = ∂y_j / ∂x_i   (第i个输入维度对第j个输出维度的影响)
```

### 2.2 计算方法

由于FeatureNormalizer不是PyTorch可导模块，我们使用**数值方法（有限差分法）**计算Jacobian：

```python
# 对于输入维度 j：
x_plus  = x + ε  # 在第j维加上小量ε
x_minus = x - ε  # 在第j维减去小量ε

grad_j = (f(x_plus) - f(x_minus)) / (2*ε)  # 中心差分近似
```

这里使用 `ε = 1e-5`，中心差分法的误差是 O(ε²)，非常精确。

### 2.3 输出的指标

1. **平均Jacobian范数**：`||J||_F`（Frobenius范数）
   - 整个矩阵的大小，反映输入→输出的总体响应强度

2. **各输入维度敏感性**：`||J[i,:]||₂`（第i行的L2范数）
   - 衡量每个输入维度对输出的总体影响程度

### 2.4 如何解读

| 指标 | 数值大 | 数值小 |
|------|--------|--------|
| 平均Jacobian范数 | 响应强烈 | 响应微弱 |
| Open敏感性高 | 模型对开盘价敏感 | 模型对开盘价不敏感 |

**典型问题**：
- 如果某个特征敏感性极低（如Volume/Exchange），可能说明该特征被"忽略"了
- 如果所有特征敏感性都极低，可能说明初始化过于保守

## 3. 局部敏感性分析

### 3.1 原理

局部敏感性分析衡量**微小扰动**导致的**输出变化**。这类似于Jacobian分析，但更直观：

```
Δoutput = ||f(x + ε) - f(x)||₂
```

我们设置 `ε = 0.0001`（非常小的扰动），然后测量输出变化。

### 3.2 计算方法

```python
# 对于每个输入维度 j：
x_perturbed = x.clone()
x_perturbed[j] += ε  # 只扰动第j维

diff_j = ||f(x_perturbed) - f(x)||₂
```

### 3.3 输出的指标

- **各维度扰动导致的输出变化**：mean ± std
- **全维度同时扰动**：所有维度同时加上ε时的输出变化

### 3.4 如何解读

| 结果 | 含义 |
|------|------|
| Open变化最大 | 模型对开盘价最敏感 |
| Volume变化最小 | 模型对成交量相对不敏感 |

**与Jacobian分析的区别**：
- Jacobian是理论上的"瞬时变化率"
- 局部敏感性是实际测量到的"变化量"
- 二者趋势应该一致，但数值表达形式不同

## 4. 全局敏感性分析

### 4.1 原理

局部敏感性分析只考察**某一点附近**的行为，全局敏感性分析则考察**整个输入空间**的行为。

对于每个输入维度，我们让该维度在**整个有效范围内变化**，观察输出的变化幅度。

### 4.2 计算方法

```python
# 对于OHLC特征（范围-0.1到0.1）：
values = np.linspace(-0.1, 0.1, 21)  # 21个采样点

for v in values:
    x_test = base_input.copy()
    x_test[:, :, j] = v  # 设置第j维
    output = f(x_test)
    outputs.append(output)

# 输出变化范围
output_range = max(outputs) - min(outputs)
```

### 4.3 输出的指标

- **平均变化范围**：输出向量各维度变化范围的均值
- **输出std**：不同输入值时输出向量的标准差

### 4.4 如何解读

| 指标 | 含义 |
|------|------|
| 变化范围大 | 该输入维度能引起输出较大变化 |
| 输出std大 | 输出空间利用更充分 |

**与局部敏感性的对比**：
- 局部敏感性：微小扰动（ε=0.0001）
- 全局敏感性：大幅变化（整个范围）

## 5. 表示多样性分析

### 5.1 原理

表示多样性分析评估**不同输入**是否产生**足够不同**的输出。如果任意两个输入都映射到相似的输出，说明Embedding层**没有有效区分**不同输入。

### 5.2 计算方法

#### 5.2.1 输入-输出距离相关性

衡量"输入越不同，输出是否也越不同"：

```python
# 采样100个样本，计算两两之间的距离
for each pair (i, j):
    input_dist  = ||x_i - x_j||₂
    output_dist = ||y_i - y_j||₂
    
correlation = pearsonr(input_dists, output_dists)
```

- **相关性高**（接近1）：输入差异被正确映射为输出差异
- **相关性低**（接近0）：输入差异没有被有效捕捉

#### 5.2.2 输出向量余弦相似度

衡量**输出空间的几何结构**：

```python
for each pair (i, j):
    cos_sim = cosine(y_i, y_j)  # 1 - 余弦距离
    
avg_cosine_sim = mean(cosine_sims)
```

- **余弦相似度高**（接近1）：输出向量方向相似，表示"聚在一起"
- **余弦相似度低**（接近0）：输出向量方向分散，表示"各具特色"

#### 5.2.3 输出向量范数

衡量**输出向量的"长度"分布**：

```python
norms = ||y_i||₂  # 每个输出向量的L2范数
```

- **范数大**：输出信号强
- **范数变化范围大**：不同输入产生显著不同的"强度"

### 5.3 如何解读

| 指标 | 好 | 坏 |
|------|-----|-----|
| 输入-输出相关性 | 高（>0.8） | 低（<0.5） |
| 输出余弦相似度 | 适中（0.2-0.4） | 极高（>0.9）或极低（<0.1） |
| 输出范数 | 较大且分布广 | 很小或很窄 |

## 6. 饱和度分析

### 6.1 原理

饱和度分析检查Embedding层输出的**数值分布**是否健康。神经网络中的"饱和"指的是：

- **激活饱和**：输入落在激活函数的"平坦区域"，梯度接近0
- **死神经元**：输出始终接近0，神经元完全"死亡"

### 6.2 计算方法

```python
outputs = f(inputs)  # 所有输出值

# 饱和：绝对值大于3（进入激活函数的饱和区）
saturation_ratio = mean(|outputs| > 3)

# 死神经元：绝对值接近0
dead_ratio = mean(|outputs| < 0.01)
```

### 6.3 激活函数的饱和区

以常见的GELU激活函数为例：

```
GELU(x) ≈ 0.5x(1 + tanh(√(2/π)(x + 0.044715x³)))

当 |x| > 3 时：
- GELU(x) ≈ sign(x) * 1  （近似饱和）
- 梯度 ≈ 0              （梯度消失）
```

### 6.4 如何解读

| 指标 | 健康 | 问题 |
|------|------|------|
| 饱和比例 | < 1% | > 10% |
| 死神经元比例 | < 5% | > 20% |
| 输出均值 | 接近0 | 明显偏离0 |
| 输出范围 | 约[-3, 3] | 远超这个范围 |

**典型问题及原因**：

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 死神经元过多 | 初始化过小、学习率过低 | 增大初始化增益、调整学习率 |
| 饱和过多 | 初始化过大、输入分布不当 | 减小初始化增益、调整归一化 |

## 7. 临界点分析

### 7.1 原理

临界点分析（二阶敏感性）检测Embedding模块的**非线性程度**。一阶导数（Jacobian）衡量"变化有多快"，二阶导数衡量"变化有多剧烈"。

数学上，二阶导数（ Hessian 矩阵的近似）：

```
∂²y / ∂x² ≈ (f(x+ε) - 2f(x) + f(x-ε)) / ε²
```

如果二阶导数很大，说明输入的微小变化会导致输出的**剧烈变化**——这可能意味着模型在该区域存在**尖锐的非线性**。

### 7.2 计算方法

```python
# 对于每个输入维度 j：
x_plus  = x + ε
x_minus = x - ε

second_deriv = ||f(x_plus) - 2f(x) + f(x_minus)||₂ / ε²
```

### 7.3 如何解读

| 指标 | 含义 |
|------|------|
| 二阶导数大 | 输入→输出的映射在该点"很弯曲"，存在尖锐变化 |
| 二阶导数小 | 映射在该点接近线性 |

**为什么关心这个**：
- 过大的二阶敏感性可能导致训练不稳定
- 如果某些区域二阶敏感性极高，可能存在数值问题
- 理想情况：二阶敏感性适中且平滑

## 8. 特征重要性分析

### 8.1 原理

特征重要性分析（消融实验/Ablation Study）回答：**每个输入特征对输出有多重要？**

核心思想：如果我们"移除"某个特征（设为某个基准值），输出会发生多大变化？变化越大，说明该特征越重要。

### 8.2 关键：语义正确的"零值"

不同特征的"基准值"含义不同：

| 特征 | 粗处理后范围 | 基准值（设为0的含义） | 语义正确的基准值 |
|------|-------------|---------------------|-----------------|
| Open/High/Low/Close | [-0.1, 0.1] | 0 = 中间（不涨不跌） | 0.0 |
| Volume | [0, 1] | 0 = 成交量暴跌500% | **0.5**（变化率为0，维持不变）|
| Exchange | [0, 1] | 0 = 换手率0% | **0.01**（1%换手率，普通股票）|

### 8.3 计算方法

```python
# 定义语义正确的零值
zero_values = {
    'Open': 0.0,
    'High': 0.0,
    'Low': 0.0,
    'Close': 0.0,
    'Volume': 0.5,    # 成交量变化率为0
    'Exchange': 0.01  # 1%换手率
}

# 对每个特征进行消融
for each feature j:
    x_ablated = x.copy()
    x_ablated[j] = zero_values[j]  # 设为基准值
    
    output_original = f(x)
    output_ablated = f(x_ablated)
    
    relative_change = ||output_ablated|| - ||output_original|| / ||output_original||
```

### 8.4 如何解读

| 排序 | 特征重要性 | 解读 |
|------|-----------|------|
| 1 | High 16.90% | 最高价对模型预测最重要 |
| 2 | Close 12.45% | 收盘价次重要 |
| 3 | Low 10.86% | 最低价也有较大影响 |
| 4 | Exchange 9.86% | 换手率有一定影响 |
| 5 | Volume 6.31% | 成交量影响相对较小 |
| 6 | Open 1.99% | 开盘价影响最小 |

**注意**：
- 特征重要性之和不一定等于100%（可以超过，因为是相对变化）
- 特征重要性反映的是"有 vs 无"的差异，不是"权重"

## 9. 总结：如何解读评估结果

### 9.1 核心指标速查表

| 指标 | 好的范围 | 问题信号 |
|------|---------|----------|
| Jacobian范数 | 5000-15000 | < 2000（太弱）或 > 20000（可能不稳定）|
| 输入-输出相关性 | > 0.8 | < 0.5 |
| 输出余弦相似度 | 0.2-0.4 | > 0.9（太相似）或 < 0.1 |
| 饱和比例 | < 1% | > 10% |
| 死神经元比例 | < 5% | > 20% |

### 9.2 典型问题诊断

| 问题 | 表现 | 解决方案 |
|------|------|----------|
| **初始化过于保守** | Jacobian小、范数小、死神经元多 | 增大初始化增益 |
| **初始化过于激进** | 饱和比例高、二阶敏感性强 | 减小初始化增益 |
| **特征被忽略** | 某特征敏感性极低 | 检查归一化或数据处理 |
| **表示能力不足** | 输出余弦相似度高 | 增加d_model或层数 |

### 9.3 实际应用示例

参考最新训练模型（AUC≈70%）的评估结果：

```
好的表现：
- 输出向量范数：22.18（大而稳定）
- 死神经元：1.72%（非常健康）
- 饱和：0.30%（轻微，可接受）
- 特征重要性：High > Close > Low（符合业务逻辑）
```
