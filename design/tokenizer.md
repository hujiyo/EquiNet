# Tokenizer 的 6 维特征分桶策略详解

> 2026.3.8 add
> src/tokenizer.py

## 核心设计理念

Tokenizer 采用**独立 token 空间 + 非均匀分桶**策略，针对不同特征的数据分布特点进行差异化设计。

---

## 一、价格类特征（开盘/收盘/最高/最低）- 均匀分桶

### 1. **开盘价 (Open)** - Token ID: 0-19

**归一化范围**: [-0.1, 0.1]（相对前一日收盘价的涨跌幅）
- -0.1 表示下跌 10%
- 0.0 表示持平
- +0.1 表示上涨 10%

**分桶策略**: 20 个均匀桶，步长 1%
```
桶0:  [-10.0%, -9.0%)  → Token 0
桶1:  [-9.0%,  -8.0%)  → Token 1
...
桶10: [0.0%,   +1.0%)  → Token 10
...
桶19: [+9.0%, +10.0%]  → Token 19
```

### 2. **最高价 (High)** - Token ID: 20-39
### 3. **最低价 (Low)** - Token ID: 40-59
### 4. **收盘价 (Close)** - Token ID: 60-79

**设计相同**，仅 token ID 偏移量不同，确保每个价格特征有独立的 embedding 空间。

**设计原因**:
- A股涨跌停限制 ±10%，覆盖完整价格波动范围
- 1% 步长精度足够捕捉日内价格变化
- 均匀分桶符合价格变化的对称性分布

---

## 二、量能 (Volume) - 非均匀分桶（两段式）

### Token ID: 80-115（共 36 个桶）

**归一化公式**: 
```
原始值 = (V_t - V_{t-1}) / V_{t-1}  # 相对前一日的成交量变化
归一化值 = clip(原始值 / 10 + 0.5, 0, 1)
```

**分桶策略**: 两段式非均匀分桶

#### **区间一 [0, 0.6]**: 20 个桶（Token 80-99）
- **对应原始变化**: -100% 到 +100%
- **步长**: 3%（归一化后）= 10%（原始变化）
- **覆盖场景**: 常规成交量波动

```
桶0:  归一化[0.00, 0.03) → 原始[-100%, -90%)  → Token 80
桶1:  归一化[0.03, 0.06) → 原始[-90%,  -80%)  → Token 81
...
桶10: 归一化[0.30, 0.33) → 原始[0%,    +10%)  → Token 90
...
桶19: 归一化[0.57, 0.60] → 原始[+90%, +100%]  → Token 99
```

#### **区间二 [0.6, 1.0]**: 16 个桶（Token 100-115）
- **对应原始变化**: +100% 到 +500%
- **步长**: 2.5%（归一化后）= 25%（原始变化）
- **覆盖场景**: 放量突破、异常放量

```
桶20: 归一化[0.60, 0.625) → 原始[+100%, +125%)  → Token 100
桶21: 归一化[0.625, 0.65) → 原始[+125%, +150%)  → Token 101
...
桶35: 归一化[0.975, 1.0]  → 原始[+475%, +500%]  → Token 115
```

**设计原因**:
- 成交量变化呈**长尾分布**，大部分在 ±100% 内
- 区间一用细粒度（10%）捕捉常规波动
- 区间二用粗粒度（25%）覆盖极端放量，节省 token 数量
- 0.5 对应 0% 变化，保持数值对称性

## 三、换手率 (Exchange) - 非均匀分桶（两段式）

### Token ID: 116-175（共 60 个桶）

**归一化公式**:
```
原始值 = 换手率百分比（0-100%）
归一化值 = clip(原始值 / 100, 0, 1)
```

**分桶策略**: 两段式非均匀分桶

#### **区间一 [0, 0.2]**: 40 个桶（Token 116-155）
- **对应原始值**: 0% 到 20%
- **步长**: 0.5%（原始换手率）
- **覆盖场景**: 低换手率区间（大部分股票日常状态）

```
桶0:  归一化[0.000, 0.005) → 原始[0.0%,  0.5%)  → Token 116
桶1:  归一化[0.005, 0.010) → 原始[0.5%,  1.0%)  → Token 117
...
桶10: 归一化[0.050, 0.055) → 原始[5.0%,  5.5%)  → Token 126
...
桶39: 归一化[0.195, 0.200] → 原始[19.5%, 20.0%] → Token 155
```

#### **区间二 [0.2, 1.0]**: 20 个桶（Token 156-175）
- **对应原始值**: 20% 到 100%
- **步长**: 4%（原始换手率）
- **覆盖场景**: 高换手率区间（活跃交易、题材炒作）

```
桶40: 归一化[0.20, 0.24) → 原始[20%, 24%)  → Token 156
桶41: 归一化[0.24, 0.28) → 原始[24%, 28%)  → Token 157
...
桶59: 归一化[0.96, 1.00] → 原始[96%, 100%] → Token 175
```

**设计原因**:
- 换手率呈**极度偏态分布**，80% 的交易日在 0-20% 区间
- 区间一用细粒度（0.5%）精确区分低换手率状态
- 区间二用粗粒度（4%）覆盖高换手率，避免 token 浪费
- 低换手率的微小差异对交易决策影响更大

## 总体架构

### Token 空间分配
```
特征         Token范围    桶数   策略
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
开盘价       0-19        20    均匀
最高价       20-39       20    均匀
最低价       40-59       20    均匀
收盘价       60-79       20    均匀
量能         80-115      36    非均匀（20+16）
换手率       116-175     60    非均匀（40+20）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
总计         176个token
```

### 关键优势

1. **独立 token 空间**: 每个特征有独立的 embedding，避免语义混淆
2. **非均匀分桶**: 根据真实数据分布优化，高频区间细粒度，低频区间粗粒度
3. **精度与效率平衡**: 总词表仅 176，远小于均匀分桶（需 300+ tokens）
4. **可解释性强**: 每个 token 对应明确的数值范围，便于调试和分析

这种设计确保模型能够精确捕捉关键价格信号，同时对量能和换手率的异常变化保持敏感。
