# Embedding 模块评估方法详解

`embedding_evaluator.py` 各评估环节的原理说明。

评估对象：粗处理后数据 → 细处理(FeatureNormalizer) → FFN-Embedding(Linear(15→128) + 残差 GELU 分支)

---

## 1. 跨维度交互分析

单个特征的线性变换无法捕获特征间的交互关系（如"上影线 = High 远大于 Close"）。此检测衡量两个特征同时变化时，输出是否不同于各自单独变化的叠加：

```
交互效应 = f(x + Δa + Δb) - f(x + Δa) - f(x + Δb) + f(x)
```

检测的特征对：Open-Close、High-Low、Close-VWAP、Close-Amount。

| 结果 | 含义 |
|------|------|
| 交互效应显著 | 非线性层学到了特征组合（如区分"高开低走"和"低开高走"） |
| 交互效应 ≈ 0 | Embedding 退化为线性映射 |

---

## 2. 方向对比敏感性

股票市场中，符号翻转（Close 从 +3% 变为 -3%）通常比同向平移（+3% → +5%）含义变化更大。此测试比较两种扰动的输出响应：

```
方向对比比 = ||f(+δ) - f(-δ)||  /  ||f(+δ) - f(0)||
```

- 比值 > 1：对方向变化更敏感
- 比值 ≈ 1：对两种变化同等敏感
- 比值 < 1：对方向变化反而更迟钝

期望 OHLC 的比值 > 1（涨跌方向是最基本的市场信号）。

---

## 3. 语义模式分析

评估脚本定义了一组原型交易日模式（粗处理后的 15 维空间），检查 Embedding 空间中的距离是否符合金融语义：

| 模式 | 含义 | 关键特征值 |
|------|------|-----------|
| bullish_large | 大阳线 | Close=+4%, High=+5% |
| bearish_large | 大阴线 | Close=-4%, Low=-5% |
| doji | 十字星 | OHLC≈0 |
| high_vol_bull | 放量上涨 | Close=+3%, Amount=+85% |
| low_vol_bull | 缩量上涨 | Close=+3%, Amount=+35% |
| upper_shadow | 长上影线 | High=+6%, Close≈0 |
| lower_shadow | 长下影线 | Low=-6%, Close≈0 |
| high_ex_limit | 高换手涨停 | Close=+10%, Exchange=+15% |

验证规则：
- **语义对立对**应距离远：大阳线 vs 大阴线、放量上涨 vs 缩量上涨、长上影线 vs 长下影线
- **语义相似对**应距离近：大阳线 vs 放量上涨、缩量上涨 vs 跟风上涨

---

## 4. 高维连续性

沿关键特征维度均匀采样，绘制 Embedding 输出随特征变化的轨迹。检查：
- **平滑性**：相邻采样点的输出是否平滑（无突变跳变）
- **边界行为**：极端值处输出是否发散或饱和

---

## 5. 信息保留度

用线性层尝试从 Embedding 输出重建原始输入特征：`重建误差 = ||W · f(x) - x||₂`

| R² | 含义 |
|----|------|
| > 0.9 | 原始信息充分保留 |
| 0.5 ~ 0.9 | 部分信息丢失（可能是有意义的压缩） |
| < 0.5 | 信息丢失过多 |

---

## 6. 饱和度分析

检查 Embedding 层输出的数值分布：

| 指标 | 正常范围 | 异常阈值 |
|------|---------|---------|
| 饱和比例（\|output\| > 3） | < 1% | > 10% |
| 死神经元比例（\|output\| < 0.01） | < 5% | > 20% |
| 输出均值 | ≈ 0 | 明显偏离 0 |

---

## 7. 特征消融

逐个将特征设为语义基准值，测量输出变化幅度。基准值选择：

| 特征 | 基准值 | 语义 |
|------|--------|------|
| OHLC | 0.0 | 不涨不跌 |
| VWAP | 0.0 | 均价 = 收盘价 |
| Amount | 0.5 | 成交量变化率为 0 |
| Exchange | 0.01 | 1% 换手率 |
| MA偏离度 / MACD / BB | 0.0 | 零轴处 |

期望的特征重要性排序：High/Low > Close > 技术指标 > Open（开盘价是已知信息，信息量最少）。

---

## 问题诊断速查

| 表现 | 可能原因 | 调整方向 |
|------|---------|---------|
| 交互效应 ≈ 0 | 非线性能力不足 | 检查 GELU 激活是否生效 |
| 方向对比比 < 1 | 方向信息丢失 | 检查归一化是否抹平了正负差异 |
| 对立模式距离近 | 语义编码混乱 | 检查训练数据或增加对比学习 |
| 重建 R² < 0.5 | 信息丢失过多 | 增大 d_model 或检查残差连接 |
| 死神经元 > 20% | 初始化过小 | 增大初始化增益 |
| 饱和 > 10% | 初始化过大 | 减小初始化增益 |
