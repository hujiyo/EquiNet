> 目标读者：项目全体成员与在仓库上协作的 Agent。结论按**优先级金字塔**组织：P0 不做完，P1/P2 的任何结论都无法被验证。

## 0. 写在前面：定位与总体判断

先说结论，也先说公道话。

**你们不是业余水平。** `model.py` 的 per-head Q/K RMSNorm、SwiGLU、Post-Norm、零初始化输出头配先验 bias，`data.py` 的向量化批处理、标签距离保护、两阶段归一化、以及**归一化只在训练集上拟合**（无泄漏，`data.py:1602`）——这些细节里有一半是很多"正规军"都会做错的地方。`pretrain_embedding.py` 里"线性解码器逼 embedding 编码跨维关系，非线性解码器会把压力吞掉"这条洞察，是对的，而且是你们自己想清楚的。这些我都记在账上。

**但你们优化错了层。** 你们把绝大部分精力花在了模型结构和预训练栈上——这是**好玩的部分**；而决定"任何一个数字到底有没有意义"的**评估方法论，是坏的**。这是业余团队最经典的失败模式：在测量体系不可信之前，就去雕琢被测量的东西。你们现在等于在用一把没校准的尺子，反复量一根正在被雕刻的木头，然后为刻度的抖动争论不休。

**核心论断（这一句是全文最重要的一句）：**
当前 README 与日志里的所有回测收益率，是「**幸存者偏差 + 零交易成本 + 选择偏差**」三重叠加后的**上界**，**不是期望收益**。真实期望收益完全可能在减去成本并修正偏差后落到 0 附近甚至为负。**在 P0 修复之前，请停止一切"哪个架构更好"的争论**——因为现在的评估体系根本无法分辨两种架构的好坏。

## 1. 优先级金字塔

| 层级 | 主题 | 杠杆 | 什么时候做 |
|---|---|---|---|
| **P0** | 可信度：幸存者偏差 / 交易成本 / 选择偏差 / 阈值回看 | **决定生死** | 立即，先于一切 |
| **P0/P1** | 评估协议：point-in-time、基准、walk-forward、因果阈值、模型选择协议 | 让数字变可信 | 与 P0 同步 |
| **P1** | **真正的架构赌注：横截面（cross-sectional）** | 最大的性能天花板 | P0 验证后立刻 |
| **P1/P2** | 预训练栈：先砍、再证（消融是唯一裁判） | 很可能为负收益 | P0 之后 |
| **P2** | 模型本体（尺寸/位置编码/正则） | **不是瓶颈** | 最后，且多半不用动 |
| **P2** | 标签设计 | 中 | 随横截面一起改 |

一句话：**先修尺子（P0），再换被量的东西（P1），最后才去打磨刻度（P2）。**

## 2. P0：可信度（先修，再谈别的）

### 2.1 幸存者偏差（survivorship bias）—— 最致命

**现状**（已实测）：`data_maintenance/select.py`
- `_batch_market_caps` 用 `get_latest_records_batch` 取**最新一个交易日**的流通市值（`amount*100/exchange`）；
- `select()` 按今日市值 / 非 ST / 代码前缀筛出约 2260 只；
- `_active_filter` 明确**排除退市与长期停牌股**（`select.py:9,58,78`）；
- 然后把这批"活到今天"的股票的 **2016–2026 全历史**用于训练与回测。

**为什么致命**：你用"今天的幸存者"去回测过去十年。退市的、崩掉的、被借壳的股票根本不在池子里，而它们恰恰是当年最被模型可能选中的高波动标的。这等于**在事后才知道谁活下来，再假装当年只买了这些**。任何择时/选股策略在幸存者池上的回测都会系统性高估收益，短周期、高换手、选小盘股的策略被高估得最狠——而你们的策略恰好三条全占。

**修法**：股票池必须 **point-in-time（带生效日期的快照）**。
- 保留退市股的历史数据直到退市日；
- 市值/ST/上市状态的判断必须用**当日**（或当日已知的最新）数据，而不是最新一日；
- 最简单可落地的第一步：**至少把退市股加回池子**，即便市值过滤暂时仍用近似，也能立刻消掉最粗的一层偏差。

### 2.2 交易成本（transaction cost）—— 数字直接腰斩

**现状**（已实测）：`training_utils.py:calculate_portfolio_simulation` 全程
`released = h['amount'] * (1.0 + h['return'])`，**没有任何成本项**。全库 grep 手续费/滑点/印花税/commission/slippage/成本 **零命中**。

**为什么致命**：你们是 **3 天持有、每天换手、4 只集中持仓、选 10–200 亿中小盘**。A 股这类账户的双边成本现实估计：
- 佣金 ~0.025%/边（还有最低 5 元/笔，小单会被吃掉）；
- 印花税 0.05%（卖出单边）；
- 滑点 + 冲击：中小盘、4 只集中、按开盘价成交，0.2–0.5% 很平常。
→ **现实双边成本 0.3%–0.6%+**。

而你们报的**毛**收益均值才 ~+0.9% ～ +1.5%/日（且是被下面 2.3 抬高过的）。**成本一口就吃掉毛收益的 30%–50%**。这还没算选择偏差修正（会再砍一刀）。

**修法**：`calculate_portfolio_simulation` / `calculate_realistic_return` 里**必须**进成本：
- 卖出侧加印花税、买卖各加佣金、按成交额加滑点；
- 保守配置：**双边 0.3% 起，再用 0.5% 做敏感性**；成本做成配置项（`DataConfig`）。
- **永远同时报毛/净两条曲线**。净收益才是能拿到手的。

### 2.3 选择偏差 / 多重比较（selection bias）—— 把噪声当信号

**现状**（已实测）：`train.py`
- 每一轮在**验证集（仅 2025 一年，约 195 个交易日）**上跑实盘模拟，`realistic_return > best_realistic_return` 就把当前模型 `deepcopy` 存盘；
- 取 **80 轮里的历史最大值**当作"最佳模型"，并把它的收益写进文件名与 README；
- 选模型的指标 = 你最后对外报的指标，**训练集/验证集职责没有隔离**；
- 另有硬编码门槛 `stats['top_return'] >= 0.006 and stats['auc'] > 0.69` 才存 loss 模型——这些魔法数是**照着验证集手感调出来的**，本身就是过拟合。

**量化这笔偏差**：验证集日收益 std≈5%、195 天 → 单次估计的标准误 ≈ 5%/√195 ≈ **0.36%**。但你是**从 80 个高度相关的估计里取最大**，max-of-80 的乐观偏移轻松 1–2 个标准误 ≈ **0.4%–0.7%/日**。也就是说，你日志里那个"+1%~1.5%"，**还没扣成本，就可能已经虚高了接近一半**。

**修法**：
- **测试集只跑一次**，且**永远不用"你要报的那个指标"去选模型**。要么按 val loss 选、只报 test；要么用嵌套（walk-forward 内层选、外层评）。
- 把"取 80 轮最大值"改成"**预先指定决策规则**"（例如：warmup 后 val loss 最低的那一轮），不要在验证集上摸最大。
- 魔法数门槛删掉。

### 2.4 阈值回看（look-ahead）—— 隐性未来函数

**现状**（已实测，`training_utils.py:evaluate_model` 与 `run.py`）：
```
top_k = int(len(all_preds) * TOP_K / 100)
threshold = all_preds[ argsort(all_preds)[::-1][top_k-1] ]   # 用整个评估集（含未来）定阈值
```
全局阈值是**把评估期所有交易日的预测分池化后**取的分位点。实盘当天你**不可能**知道未来所有日子的分数分布，因此这个阈值编码了未来信息。

**修法**：阈值必须**因果**——用**滚动/扩展窗口的历史分位数**（例如过去 60 天的分数分布定今天的阈值），或直接改用**逐日横截面排名**（见 §4，这本来就是更对的做法）。

### 2.5 零样本日被剔除的隐性乐观

**现状**（已实测，`calculate_realistic_return`）：`avg_realistic_return = mean(daily_returns)`，而 `daily_returns` **只在当天有选股时才 append**；空仓日 `daily_stats.append((0,0.0))` 但**不进均值**。于是"模型没找到票的日子"被静默剔除，均值只在"它敢出手的日子"上计算——又一层乐观。

**修法**：空仓日应记 0 收益并计入分母（或明确声明"仅在有持仓日有效"，但要与实盘口径一致）。

## 3. P0/P1：评估协议（让数字变可信）

修完 §2 的四个洞之后，把评估固化成一个**没人能偷懒绕过**的统一入口（建议 `src/backtest.py`），至少强制产出：

1. **point-in-time 股票池**（含退市股，市值/状态按当日）。
2. **交易成本**（毛/净双曲线，成本可配置，含印花税+佣金+滑点）。
3. **基准对比**：沪深 300 / 中证 500 / 等权多头，报 **超额收益**，而不是绝对收益。现在全库**没有任何基准**（grep `benchmark/hs300/超额` 仅命中 matplotlib 参数）。
4. **风险指标**：年化 Sharpe、最大回撤、胜率、日收益 t 统计量、换手率、容量（4 只持仓下能装多少钱）。当前只有均值和一根 sparkline。
5. **walk-forward（扩展窗逐年重训）**：报**逐年收益的分布**，不是一个 cherry-picked 的单点数字。看到收益在哪几年为负，比看到"平均 +1%"重要一百倍。
6. **统计显著性**：日收益 t 统计量、Newey-West 调整（3 天持有 ⇒ 收益重叠 ⇒ 自相关，必须调）。
7. **模型选择协议**：内层选、外层评；测试集一次性。

> 记忆里已经跑出的信号是真实存在的：Prec@1% 0.23 vs 基线 0.069（3.3 倍），验证 AUC ~0.71。**这说明"预测能力"确实有**。我要修的是"预测能力"到"可赚的钱"之间那段被三重偏差污染的换算，不是否定信号本身。这个区别很重要。

## 4. P1：真正的架构赌注 —— 横截面（cross-sectional）

**这是我作为架构评审给出的最大一条性能天花板建议，比换任何模型结构都重要。**

**现状**：模型对**每只股票独立打分**——一个 45 天窗口进，一个概率出。它在 45 天里只看这一只票自己的 19 个特征（OHLCV + 均线 + MACD + 布林 + K 线形态占比）。**输入里没有任何市场/板块/同行信息**（`ModelConfig.INPUT_DIM=19` 全是本股序列特征）。

**问题**：但你的任务本质是 **每天在全市场里横截面排序、选前 N**。这是一个 **ranking / cross-sectional** 问题，而你用了一个 **pointwise / 独立打分** 的模型去解。这两者之间有一道鸿沟：
- 模型无法知道"今天市场是 risk-on 还是 risk-off"，无法知道"这只票相对同行是强是弱"；
- 它对每天的绝对分数没概念，只能靠事后用一个（还带未来信息的）全局阈值去切——这正是 §2.4 的病根之一。

**旁证**：`config` 里的 **极端行情过滤**（剔除普涨/普跌日）本质上就是**给"缺市场上下文"打的一个补丁**——因为模型看不到市场，只好把市场层面的噪声日整段扔掉。**正确做法不是扔数据，是把市场上下文作为输入喂给模型。**

**修法（按成本递增）**：
1. **加横截面/市场上下文特征**（最便宜、最该先做）：每只票每天的输入里附加——
   - 当日市场宽度（涨跌家数比、你们已经算好了 `market_index.py`）；
   - 板块/行业相对强度、个股相对行业的 RS；
   - 本票分数在当日全市场的分位（推理时可用昨日分布近似）。
   - 这样极端行情过滤就可以退役（或降级为样本权重），而不是丢数据。
2. **横截面归一化层**：在 embedding 之后、打分之前，对**当日全市场同批样本**做标准化（z-score / softmax 温度），让输出天然是"当日相对排名"，而不是孤立概率。这从结构上解决阈值回看问题。
3. **（进阶）set-based / 交叉注意力头**：让当日候选股之间互相看到（Set Transformer / cross-sectional attention）。这是量化里真正的主流做法，但依赖 1–2 先跑通。

**注意**：横截面改造会让"每股独立预训练 embedding"的价值进一步下降（见 §5），因为信息瓶颈从"单票单日"转移到"全市场相对关系"。

## 5. P1/P2：预训练栈 —— 先砍，再证

`pretrain_embedding.py` 是全项目最精致、也最可疑的部分。它是一个 **5 项损失**的多目标大杂烩：

```
loss = w_v·VISReg + w_r·Recon(原始+衍生) + w_c·SupCon + w_cls·CLS(粗) + w_fine·FINE(细)
```
外加 CKA 监控。每一项都有手调权重（0.6 / 1.0 / 0.2 / 0.1 / 0.1），注释里甚至自承 **"注意与 VISReg 相克"**（CLS 的可分性造多峰，VISReg 的形状项拉单峰）。

**我的判断，三条：**

**(a) 过度工程。** 五项互相拉扯的损失，是"读了很多论文但没有受控消融"的典型体征。注释里承认两项相克，这不是深度，这是**目标函数欠定**——你在用一堆手调权重去缝合一群互相打架的约束。真正的做法是：**每一项都要在消融里证明自己独立的增量**，证明不了就砍掉。

**(b) 冻结是反的（最关键）。** `train.py:569` 无条件 `model.freeze_embedding(True)`，全库**没有任何微调/解冻路径**。也就是说：一个 **45 天序列 → 3 天前瞻二分类** 的下游任务，被强制建立在一个**为"单日 K 线重建 + 单日分类"训练出来的、且被冻死的 19→128 embedding** 之上。
- 下游真正需要的信息（跨日动量、量能形态、相对强度）与"单日重建"根本不是一回事；
- 现代实践里，预训练的意义是**给一个好的初始化**，然后**微调**（整体或部分），而不是冻死。
- **我的强先验：pretrained-frozen 很可能是"随机初始化端到端 / 预训练+微调"三者里最差的一档。** 你们把最该动的部分焊死了。

**(c) 消融是唯一裁判。** 在花任何时间调 VISReg 权重之前，请先跑一个**最朴素的对照**，三行表：

| 方案 | 下游验证 AUC / 净超额收益 |
|---|---|
| A. 随机初始化，端到端训练 | ? |
| B. 预训练 + **冻结**（现状） | ? |
| C. 预训练 + **微调**（全量或分层解冻） | ? |

**如果 A ≈ C > B**（我预期如此）：预训练只是个初始化，请**解冻**，并把预训练目标**砍到 Recon + 一项几何正则**即可，SupCon / CLS / FINE 除非各自在消融里有独立正贡献，否则全部退役。
**如果 C 明显 > A**：预训练有价值，那就更该微调而非冻结，然后再做减法。
**无论如何，"冻结"这一档大概率是负资产。**

> 我不否认"线性解码器逼跨维编码"这条洞察的巧妙。但巧妙 ≠ 有效。它现在被埋在一个没有消融验证的五项损失里，等于一件好武器被装进了一把没校准的枪。

## 6. P2：模型本体（不是瓶颈，别动）

等 P0/P1 都验证过之后再看这里，而且我预计**基本不用动**：

- **尺寸合适**：d_model=128 / 6 层 / 4 头，对这个数据量（~2000 股 × ~10 年）是合理规模，**不是瓶颈**。note 里纠结"头数 4→6→8"，这是**在刻度上雕花**，先放一放。
- **Post-Norm + 零 dropout**：对高噪声金融任务，零 dropout 是站得住的选择；但配合"80 轮 + 取最大值"（§2.3）会让验证集过拟合加剧——**真正要修的是选模型的方式，不是 dropout**。
- **位置编码**：learned 对 45 长度没问题；若以后拉长上下文，RoPE 是温和升级。
- **per-head Q/K RMSNorm、SwiGLU、输出头先验 bias**：都对，保持。

**结论**：模型这一层的工程质量已经高于你们的评估与数据层。请把力气从这里挪走。

## 7. 标签设计（P2，随横截面一起改）

`generate_label` 的五条件"强势信号"规则是手搓启发式，把你们对"什么算强"的先验**硬编码**进了标签。风险：
- 规则边界脆弱（阈值 0.05 / 0.06 / 0.08 一带的样本会被任意翻转）；
- 它是"是否触发某个模式"的分类，而你们真正想要的是**未来收益的排序**。

更干净的做法（任选）：
- **连续前瞻收益回归** + 排序目标（pairwise / listwise），让模型直接学"谁更强"，而不是"谁触发了规则 5"；
- 或 **分位数标签**（未来 3 日收益在当日横截面的分位），天然对接 §4 的横截面框架。

（你们已有 `PairwiseWeightedBCE` 的基础设施，说明排序这条路你们已经铺了一半。）

另外：`POSITIVE_RATIO=0.25` 上采样 **与** `POS_WEIGHT=4.0` **在重复纠偏**，后果是**输出概率失校准**——而选股阈值恰恰依赖这个概率。二选一即可（记忆里也已标出）。概率失校准还和 §2.4 的阈值回看叠加。

## 8. 立即可执行的最小动作清单

**先做这五件（P0，做完前别碰架构）：**
1. 股票池改 point-in-time：**至少把退市股加回**（`select.py`），市值/状态判断用当日数据。
2. 给 `calculate_portfolio_simulation` / `calculate_realistic_return` **加交易成本**（印花税+佣金+滑点），毛/净双报（`training_utils.py`）。
3. **加基准 + 超额收益 + Sharpe/回撤/t 值**，空仓日记 0 进均值。
4. **修模型选择协议**：按 val loss 选、test 只跑一次；阈值改因果（滚动分位）；删魔法数门槛。
5. **walk-forward 逐年重训**，报逐年收益分布。

**然后（P1）：**

7. **上横截面**：加市场/板块/相对强度特征 → 横截面归一化层，逐步退役极端行情过滤。

**最后（P2，多半不用动）：**
8. 模型本体保持现状；标签改连续/分位数排序；上采样与 POS_WEIGHT 二选一。
